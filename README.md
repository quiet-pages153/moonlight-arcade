# 달빛 오락실

달토끼 슈팅과 별빛 블록을 브라우저에서 플레이할 수 있는 미니게임 모음입니다.

## GitHub Pages에 올리기

1. ZIP을 풀고 내부 파일과 폴더를 저장소의 루트에 올립니다. `index.html`과 `assets` 폴더가 같은 위치에 있어야 합니다.
2. 저장소의 Settings에서 Pages를 열고 Source를 Deploy from a branch로 선택합니다.
3. 업로드한 브랜치(예: `main`)와 `/ (root)`를 선택해 저장합니다.

브라우저 탭과 홈 화면용 아이콘이 연결되어 있습니다. 아이콘 원본 크기 파일은 `assets/icons/icon-1024.png`입니다.

홈에서는 같은 게임 카드를 두 번 눌러 시작합니다. 별빛 블록의 단계 테스트는 일시정지 메뉴에서 열 수 있습니다.
